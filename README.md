# CommunityHub (Week 8 - React Fundamentals)

A modern React-based community posting application built using Vite.  
This project demonstrates core React concepts including components, props, state management, event handling, and CRUD operations.

---

## 🚀 Live Demo
[View Live Project](https://iyf-s10-week-08-solfegesam.vercel.app)

---

## 📌 Project Overview

CommunityHub is a simple social-style application where users can:
- Create posts
- View a list of posts
- Like posts
- Delete posts
- Interact with a clean UI built using reusable components

This project was built as part of **IYF Season 10 Week 8 React Fundamentals**.

---

## 🧠 Key React Concepts Covered

### 1. Components
Reusable UI building blocks:
- Header
- Sidebar
- PostCard
- CreatePost
- PostList

### 2. Props
Data passed between components:
- Post title, content, author, likes
- Dynamic rendering of UI

### 3. State Management (useState)
Used for:
- Posts array
- Form inputs
- Like system

### 4. Event Handling
- onClick (like/delete)
- onChange (form inputs)
- onSubmit (create post)

### 5. CRUD Operations
- Create posts
- Read posts
- Update likes
- Delete posts
